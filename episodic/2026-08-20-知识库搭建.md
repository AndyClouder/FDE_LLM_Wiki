# 2026-08-20 · 知识库搭建

## 当天的问题
用户要求依据 LLM Wiki v2 剪藏在 FDE 工作目录构建个人知识库。

## 做了什么
1. 通读方法论原文与《FDE 读这六本书就够了》,确定 schema
2. 建立三层架构(原始层只读 / wiki 层 / schema 层)+ 四级记忆目录(inbox → episodic → wiki 语义 → wiki 程序)
3. 摄取 9 张源卡片、6 坑位页、6 概念页、6 打法页;建立 graph.md(33 实体、25 边)与 index.md
4. AGENTS.md 作为运作宪法,编码了置信度、衰减、supersession、四个标准操作(INGEST / QUERY / LINT / CRYSTALLIZE)

## 关键发现 / 决策
- 该知识域天然结构是「**坑位 → 概念 → 打法**」三轴,每本书正好堵一个坑——直接映射为图谱的 explains / fixes 边
- 用户导读含 5 个真实项目案例,作为打法的验证证据(applied-in 边),使打法页置信度达到 0.8
- 原始 PDF 未做深度摄取,源卡以 `card-only / pending` 标记,概念页暂为 working(0.6)——诚实标注,不冒充已确认事实

## 教训(可复用)
- Schema 先行:先定实体类型和关系类型,再写页面,页面间互链才不会散
- 种子内容选"已结晶"的源(导读比原书更好起步):密度高、结构清晰、一次成页
