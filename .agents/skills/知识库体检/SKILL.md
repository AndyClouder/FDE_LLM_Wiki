# 知识库体检(LINT)

对知识库做健康检查并自愈。**规则以根目录 `AGENTS.md` 为准**(尤其 §4 生命周期、§7 矛盾处理)。

## 操作步骤

### 1. 跑机器审计
```bash
python tools/lint.py
```
脚本自动检查:
- 47+ 个 wiki 页 frontmatter 九字段完整、type/status 合法
- 全部 `[[wikilink]]` 可解析(0 断链;代码段内的示例链接已豁免)
- 孤儿页(wiki 页无任何入链)
- 源卡 `ingestion` 状态(应为 full;新资料 pending 属正常,提示走摄取技能)
- index.md 统计行 vs 实际文件数
- 待摄取清单未勾选项

### 2. 处理脚本发现的问题
- **能自动修的直接修**:断链写法(`[[graph.md]]`→标准链接)、统计过期、清单漏勾——修完记 changelog
- **拿不准的只标记不动手**:在 changelog 记录问题,留给用户决定

### 3. 人工检查项(脚本不覆盖)
- [ ] **置信度衰减重算**:概念/架构类半衰期 12 个月、打法类 6 个月、瞬态事实 1 个月;`last_confirmed` 超过一个半衰期未强化 → confidence −0.1 并更新页面
- [ ] **矛盾检测**:同主题页面声明是否冲突 → 按 AGENTS.md §7 提议 supersession(新近性>权威>证据数)
- [ ] **inbox/ 无源卡的资料** → 补建源卡或提示用户走摄取技能
- [ ] `.zcode-tmp/` 等临时目录清理

### 4. 报告
输出:通过项 / 修复项 / 待人工项,三段式汇报,修复项记 changelog。

## 踩坑点(gotchas)

- 脚本退出码 1 = 有问题,**先看问题清单再动手**,不要盲目重跑
- 衰减重算要**成批做**(先扫描全部页面的 last_confirmed,统一计算,再批量编辑),逐页编辑容易漏
- 置信度下限 0.3:低于此值页面标记为遗忘候选,不删除,等用户裁决
- `[[wikilink]]` 写在反引号代码段里会被脚本豁免——文档示例一律用反引号包裹
- 修 changelog/index 时用**追加行**,不要替换既有行(历史上覆盖丢过记录)

## 可容错

- lint.py 本身报错(如 python 不在 PATH):fallback 为按 AGENTS.md §6 LINT 清单人工检查
- 单页编辑失败不阻塞其余页面检查

## 可扩展

- 新增检查项:改 `tools/lint.py` 后在 changelog 记录(工具也是知识库资产)
- L4 阶段可将本技能配置为定时任务自动执行
