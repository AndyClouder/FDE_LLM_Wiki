# inbox/ — 投喂口(原始层 + 工作记忆)

这里是知识库的**投喂口**:把任何资料(书、报告、剪藏、笔记)丢进来,就等于下达了"摄取这个"的指令。LLM 会话会定期扫描本目录,为没有源卡的资料建卡、为未深度摄取的资料排队。

## 放什么

- **大块资料**:PDF / EPUB / MD 全文 → 会得到一张源卡片,进入深度摄取队列
- **一句话观察**:读书摘录、项目想法、待验证的猜测,格式尽量:

```
- 2026-08-20 | 来源:[[书名]]/会议/实践 | 一句话观察
```

## 生命周期

- 资料文件一经放入,**本目录就是它的家**:不移动、不修改、不删除;摄取状态由 `wiki/sources/` 的源卡跟踪(`pending / card-only / full`)
- 一句话观察在 lint 时清理:成熟 → 晋升 wiki/ 页面;属于某次工作过程 → 归入 episodic/;过时 → 删除并记 changelog
- 长期滞留(>1 个月)且无人认领的条目视为遗忘候选
