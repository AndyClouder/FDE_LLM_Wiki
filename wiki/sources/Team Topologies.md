# Team Topologies

## 一句话内核
团队拓扑与协作模式的设计方法,解决 FDE 的隐痛:**项目做完,你成了永久接口,能力沉淀不下来**。核心主张:组织设计应围绕"变化的流动 + 系统反馈"优化,而不是静态组织架构图——团队(而非个人)是软件交付的基本单元。

## 全书逐章摘要(2026-08-20 全书精读)
- **Ch1 组织图的问题**:组织图反映汇报线而非真实沟通线;Pflaeging 三种结构(正式/非正式/价值创造);局部优化反例(IaC 把开通环境缩到分钟,审批委员会仍卡每周一次——瓶颈在流程);Naomi Stanford 组织设计五启发式
- **Ch2 康威定律**:"设计系统的组织,其产出的设计必然是组织沟通结构的副本"(Eric Raymond:"四个组做编译器,得到一个四遍编译器");Ruth Malan:"架构与组织冲突时,组织赢";**逆康威机动**先按目标架构设计沟通路径;限制不必要沟通(many-to-many 产生纠缠单体);天真应用的三个坑(工具塑造沟通/制造组件团队/频繁重组"像小孩做开胸手术");Adidas 80/20 重组发布频率 60 倍
- **Ch3 团队优先**:团队 5-9 人、成型 2 周-3 个月;Dunbar 分层(5/15/50/150);系统每一部分恰好归一个团队("把代码当花园照料,不是当警察巡逻");毒性成员必须移除;奖励团队而非个人;**认知负载三分类**(内在/外在/相关);**域复杂度启发式**(复杂域独占、不并两个复杂域);Team API 全要素;环境设计(ING 按 value stream 排布);警告:没有 CD/测试先行等工程实践,一切团队设计都会被架空
- **Ch4 静态拓扑**:两大反模式(临时拼凑/反复打散);Spotify 模型与照抄警告;DevOps Topologies 目录(没有放之四海的拓扑,公认反拓扑:独立 DevOps 团队变新烟囱);依赖追踪(矩阵/看板标签/Spotify 表格法,依赖上涨触发重设计);Accenture 三阶段演化(工具团队→IaaS→evangelist"目标是让自己失业")
- **Ch5 四类基本团队**:stream-aligned(端到端、九项技能属于团队、SRE 是特例、比例 6:1-9:1)/ enabling(**成本低估 10-15 倍**、律所八周指标案例、Greenleaf 之问)/ complicated-subsystem(认知负载决定而非复用决定,应很少)/ platform(**TVP 最薄可行平台**:一页 wiki 也算;分形嵌套"乌龟叠乌龟";按生产系统对待;Reinertsen 内部定价);避免烟囱(纯职能团队);存量团队映射(架构团队至多兼职 enabling)
- **Ch6 断裂面**:**七种隐藏单体**(应用/数据库/构建/发布——"分布式单体"/模型/思维/工作场所)+ **八种断裂面**(业务域 Bounded Context 首选/合规/变更节律/地理位置/风险轮廓/性能隔离/技术/Personas)+ litmus test("能否作为服务消费/提供");Poppolo 三年 16→70 人案例
- **Ch7 交互模式**:三种模式的成本结构与硬约束(见 [[团队交互登记四要素]]);Promise Theory(SemVer=承诺);按类型配模式;**用协作找到 XaaS 边界**再切换;把别扭当信号;reverse Conway 执行法(新结构建立后旧架构会抵抗,用临时 collaboration+enabling 渡过磨合)
- **Ch8 组织感知**:重要的不是形态而是"改组织的决策规则";**三触发器**(超一个团队/交付变慢/多业务服务依赖大量底层服务→platform wrapper);**运维是开发的感官输入,禁止 BAU 分离**(见 [[运维反馈与BAU断裂]]);Kotter:战略=持续的搜索、行动、学习、改变
- **结论**:四类+三模式是充分集合;TT 不充分条件(花园比喻:文化/工程/财务/愿景是土壤水肥);**起步五步**(从团队出发→识别变更流→找 TVP→识别能力缺口"没有运动队不雇教练"→演练交互模式)
- **附册 Workbook**:认知负载问卷(见 [[团队认知负载五问]]);Team API 模板(Mooz 全例);依赖追踪三法;Dunbar 信任边界(皇家 Marines 分形建制 8/30-50/100-150);在线空间按变更流切、勿按职能切;频道命名约定(#team-X/#platformteam-X/模式入名);"多沟通少文档"但要自含上下文;**交互登记四要素+超期即信号**;平台 DevEx 问卷/NPS;公共优先(public by default)
