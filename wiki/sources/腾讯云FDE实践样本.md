# 腾讯云 FDE 实践样本(报告第六章)

> 案例集页:集中收录腾讯云 FDE 实践,作为 [[四步打法]]、[[Echo与Delta能力模型]]、[[Land-and-Expand与脚手架原则]] 的验证素材与市场定价证据。

## ADP 平台四阶段演进
RAG 问答 → 工作流编排 → Multi-Agent → 自然语言构建。**门槛下降没削弱 FDE,反而把难点从"能不能搭"推向"知不知道搭什么"**——FDE 转型为场景发现者/需求翻译者/方法教练。
配套**落地四层门槛**(解释客户"买了平台却用不好"):理解需求(Echo/行业专家)→ 翻译需求(Echo+FDPM)→ 0 到 1 搭建(Delta)→ 1 到 N 调优(Delta+产品/知识工程)。

## 传媒行业:双人组合竞标
Echo 讲案例 + Delta 现场搭原型的双人组合,竞标中"**响应更快、成本更低、客户感知更强**"。交付三代演进(软硬件一体化 → 云化软件聚焦 → 智能体搭建):"技术门槛在降维、业务理解在升维"。

## 客户成功"陪跑师"(轻量 FDE)
适合教育/传媒/文旅/出版/大健康等**高容错行业**(操作精度要求不严);不需极深行业专精或极强工程,需要耐心/沟通力/快速学习——FDE 正从专职岗位走向**能力标签**。

## CodeBuddy/WorkBuddy 全链路
- 认知层:Echo 传递腾讯内部组织转型经验(一线反复出现:工具好用的关键在组织调整为 AI 改变工作方式)
- **商业闭环(全库唯一市场定价证据)**:FDE 服务已被市场验证为可独立定价能力——头部客户在工具采购外**单独为 FDE 陪跑付费,金额百万级到五百万级**(工作流梳理/人才培养/组织转型辅助/效果评测);收入结构 = 服务包与培训认证(短期)+ 持续消耗(长期引擎);席位费只是入口;以半年度为周期证明自负盈亏

## 平台/工具/伙伴三层赋能
平台(ADP 能力封装)、工具(CodeBuddy 等)、伙伴(培训认证与复制)分工;与生态节奏"0 到 1 原厂、1 到 N 伙伴"(见 [[Land-and-Expand与脚手架原则]])互为表里。
