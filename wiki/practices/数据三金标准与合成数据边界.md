# 数据三金标准与合成数据边界

## 核心打法
数据工程的取舍艺术:**quality / coverage / quantity 三金标准**;少而精胜过多而噪;合成数据只造**能验证的**数据,全合成必然 model collapse,掺真实数据是保险。

## 操作步骤
1. **质量六特征**:relevant / aligned with task / consistent / correctly formatted / sufficiently unique / compliant。少而精:LIMA 用 1000 条精选数据微调 65B,43% 的情况追平 GPT-4(但鲁棒性达不到产品级);Yi 团队 1 万条精制指令 > 数十万条噪声
2. **覆盖**:训练数据要匹配用户真实表达(有错别字就放错别字);任务多样性 9→282 个大涨、1836 后趋平;"The Data Addition Dilemma":异质数据加多了可能更差
3. **数量看三因素**:微调技术(全量数千~百万、PEFT 数百~数千)/ 任务复杂度 / 底座强弱(数据少→PEFT+强模型;数据多→全量+小模型)。**先做 50-100 条小数据试验**:没改善,大数据很少能救(先排除超参/质量/prompt 问题)
4. **获取**:最优数据源 = 自己的应用数据(data flywheel,分布完美匹配);公开数据集必须验证不可全信;"It's hard to annotate data, but it's even harder to create annotation guidelines"——评测指南可复用为标注指南
5. **处理四步**:inspect(**人工盯数据 15 分钟价值最高**,"Manual inspection of data has probably the highest value-to-prestige ratio of any activity in machine learning")→ dedupe(Anthropic:0.1% 数据重复 100 次,800M 模型退化到 400M 水平)→ clean & filter(标注 session 后半程质量下降——标注者疲劳)→ format(推理时 prompt 与训练格式严格一致,多一个空格都出问题)

## 合成数据边界
- 五动机:增量(稀缺场景)/ 覆盖(对抗样本)/ 质量(工具使用数据 AI 标注比人合适)/ 隐私 / 蒸馏
- 高价值模式:**reverse instruction**(用现有高质量长内容反推指令,回答是真内容,避开生成幻觉);Llama 3 代码合成管线:AI 生成题面 → 多语言解题 → AI 生成单元测试 → 失败者带报错自修复(20% 解被自纠错)→ back-translation 验证
- **四限制**:质量不可控 / 表面模仿(Gudibande:学生学到的是"像答案的样子"= 系统性教幻觉)/ **model collapse**(递归训练 AI 数据不可逆退化;**全合成必崩,混真实数据可避免**,最佳比例无定论)/ lineage 模糊(老师的版权违规与基准污染会传染给学生)
- 验证原则:**人们只合成能验证的数据**(coding 最流行正因可执行验证)

## 蒸馏边界(2026-08-20 第二轮补入)
- DistilBERT 小 40% 保 97% 能力快 60%;BuzzFeed LoRA+蒸馏省 80% 推理成本;Nemotron 学生反超老师
- 但 Llama 3 实测:**不加验证地用自生成数据,性能不升反降**
- License 红线:多数模型协议禁止用其输出训练模型(Llama 协议仍禁)——蒸馏前查条款
