# FDE 人才画像与市场定价

## 一句话内核
结构性结论(技能结构/软技能权重/经验分布/面试法/职业分化)比瞬态数字更耐用;市场呈"**强 FDE 高溢价、弱 FDE 普通化**"分化。

## 展开
**技能结构**(报告自采 273 条 JD / 208 家公司,2026-04/06 采集,瞬态数字仅供参考):
- 技术 Top5:软件工程与全栈 88.3% / 数据分析 79.9% / 云平台 71.8% / ML 应用 61.2% / API 集成 56.4%(LLM 应用开发 50.5%);单项前三:Python 72.5%、SQL 64.5%、客户沟通 60.1%
- 软技能 Top5:**客户沟通与需求翻译(核心必备)**、**复杂问题现场拆解(核心必备)**、跨职能推进、技术演示、自驱学习;69.2% 的 JD 明确"直接与客户工作",45.4% 要求"在模糊环境中成长";经验 3-5 年占 46.5%
- 工作方式(Perspective AI 1200 人调查):47% 时间客户对接 / 31% 编码 / 22% 内部协调;**64% 的主要工作是"现有产品部署到新客户环境 + 大量定制"**(纠偏:多数 FDE 不是从零建新产品);远程仅 9%,52.4% 要求出差

**市场定价**(瞬态,标注采集时点):
- 海外均值 $196K / 中位 $187.5K,主体 $150-200K(42.5%);前沿 AI 实验室入门 $295K → Staff $725K → 主任 $1.05M,股权占比升至 55-70%
- 国内四层:初级 8-25K / 中级 25-45K / 高级 45-70K / 负责人 60-85K 或年包 80-150 万+;猎聘平均月薪仅 2.07 万 → 长尾未高薪化

**面试法(招聘版 [[关键三问清单]])**:
- AI 时代简历项目经历更易包装 → **直接模拟客户场景**:给候选人一个模糊业务问题,限时完成澄清需求、提出方案、识别风险、设计验证指标——"问概念毫无意义"

**职业四分化**:行业解决方案负责人 / 产品负责人 / 客户成功或商业 / 创业(FDE 每天训练的能力天然对接创业);年轻人路径 = 先打牢工程底子 → 客户项目积累业务理解 → **从 Delta 走向 Echo**。

**中美七维结构差**:成熟度/薪资/雇主/利润支撑/岗位认知/组织授权/产品沉淀——国内审批链长、现场授权不足、易陷一次性定制(与 [[中国FDE市场特征与经济性]] 互证)。从业者类比:"十年前的产品经理",预计火爆 5-10 年后常态化。
