# 采样参数与结构化输出五层

## 一句话内核
模型输出是概率采样而非确定查询——**一致性是投产基本要求而非优化项**;结构化输出按介入深度分五层,前三层是创可贴,后两层是重度治疗。

## 展开
**采样参数**:
- temperature(高温增创意降一致)/ top-k / top-p(nucleus,典型 0.9-0.95)/ 停止条件;logprobs 的用途与 API 限制
- **概率本性**:同一评分 prompt 两次得 3/5 与 5/5;固定采样参数只是必要非充分——"a teacher who gives you consistent scores only if that teacher sits in one particular room";"The chances are low, but never zero"(任何非零概率的输出都可能被生成)

**Test-time compute(推理时算力)**:
- best-of-N 采样;OpenAI 数学实验:**加 verifier 的性能提升 ≈ 模型扩大 30 倍**
- 采样增益有上限(实验中 400 outputs 后反降);DeepMind 主张扩展推理时算力可优于扩展参数

**结构化输出五层**(介入深度递增):
1. Prompting(说清格式)
2. 后处理(LinkedIn 防御性 YAML parser:90%→99.99%)
3. Test-time compute(多次采样选合规)
4. 约束采样(语法约束,强制合法)
5. 微调(加分类头)
- 原则:从第 1 层试起,达不到再下沉——与 [[模型适配的优先级顺序]] 同一"由轻到重"哲学
